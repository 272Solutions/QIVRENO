# Grant Application Checklist

A repeatable pass to run before any grant submission.

1. **Eligibility** — confirm entity type, geography, and years operating match the solicitation. Stop here if any fail.
2. **Deadline** — record the funder's stated time and timezone. Work back and set an internal deadline three business days earlier.
3. **Compliance matrix** — list every requirement in the solicitation and the section that answers it.
4. **Narrative** — need statement backed by cited data, measurable outcomes with baselines, and an evaluation plan.
5. **Budget** — every line reconciles to the narrative; indirect within the funder cap; justification written.
6. **Attachments** — financials, letters of support, registrations, board list.
7. **Final read** — one pass against the compliance matrix, one against the scoring rubric.
